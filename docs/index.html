A Google Drive connection.

This OAuth app, named rclone, is owned by nomad7cs for a personal file-sync setup.

It connects the rclone command-line tool to the owner’s Google Drive account. Sync commands can transfer files between a chosen local directory and a chosen Drive folder.

This is information about a personal setup. It is not a public file-sync service, and this website does not ask you to sign in to Google or access your Drive.

How it works

Files move through rclone.

The owner runs rclone on the laptop and authorizes it through Google’s consent screen. Rclone then communicates directly with Google Drive for the configured file operations.

The OAuth permission allows rclone to read, create, change, and delete Drive files. The folders and transfer direction are chosen in the local rclone commands; a sync command can also remove destination files to match its source.

This informational website does not receive Drive files, OAuth credentials, or access tokens.
