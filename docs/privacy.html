Privacy policy

For the OAuth app named rclone, owned and used by nomad7cs to sync a personal laptop directory with Google Drive.

Last updated: 11 October 2026

Purpose and scope

This app is a personal authorization setup for the rclone command-line tool. It is not offered as a general public service. This policy describes the configured Google Drive permission, the intended file-sync use, and this informational website.

Google Drive access

The app requests the full Drive permission, https://www.googleapis.com/auth/drive. This permits reading file contents and metadata, and creating, changing, or deleting Drive files. Rclone’s full-access scope excludes the Application Data Folder.

The intended use is syncing the owner’s selected files between the laptop and Google Drive. Local configuration and commands choose which folders to operate on; the OAuth permission itself is broader than one selected folder.

See rclone’s scope documentation and Google’s Drive permissions documentation.

How data is used and transferred

Rclone runs on the laptop and communicates directly with Google Drive to perform the owner’s configured operations. These can include listing files, comparing metadata, transferring file contents, and changing or deleting destination files.

This informational website does not request a Google login, receive Drive files, or receive OAuth credentials or tokens. The personal setup is intended to use Google data only for the file operations chosen by the owner, without using that data for advertising or selling it.

This personal app’s use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Synced files are stored in the local directories and Google Drive locations chosen by the owner. They remain there until the owner or a configured file operation changes or deletes them. Google Drive trash and retention behavior are governed by Google’s service.

Rclone stores OAuth client credentials and authorization tokens in its local configuration on the laptop. This policy does not claim that the configuration is encrypted. Local configuration, filesystem permissions, backups, and any logs are controlled by the owner.

Revoking authorization stops future authorized Drive access; it does not automatically delete existing local copies, Drive files, or the local rclone configuration.

Control and revocation

The owner can stop rclone, change its configuration or commands, delete local copies, and manage files in Google Drive. Access can be revoked in Google Account third-party connections by removing this app’s connection.

Local credentials and tokens can also be removed by deleting the corresponding rclone remote or its configuration. After revocation, a new authorization is required to reconnect.

Website hosting

This website includes no additional analytics, advertising, cookies, login form, or scripts. When hosted on GitHub Pages, GitHub handles technical request metadata; GitHub documents that visitor IP addresses are logged and stored for security purposes.

Hosting practices are described in the GitHub Privacy Statement and GitHub Pages data-collection documentation. Following external links is subject to those services’ own policies.

Owner and contact

The OAuth app owner is nomad7cs. Public profile information and available contact options are at github.com/nomad7cs.

This policy should be updated if the personal setup’s data use or hosting changes.
